# An Exploration of Quintic Hermite Splines to Solve Burgers' Equation

This repository contains the numerical solvers and computational code used to validate an innovative collocation scheme using quintic Hermite splines to solve the nonlinear Burgers' equation directly.

## Methodology
* Implemented a custom collocation framework.
* Validated computational efficiency and error tolerances across multiple varying initial conditions.

## Tech Stack
* **Language:** MATLAB / Fortran
* **Mathematical Tools:** Numerical Analysis, Spline Collocation, PDE Solvers

## Publication Reference
Arora, S., Kaur, I., & Tilahun, W. (2019). An exploration of quintic Hermite splines to solve Burgers' equation. *Arabian Journal of Mathematics.* https://doi.org/10.1007/s40065-019-0237-9
